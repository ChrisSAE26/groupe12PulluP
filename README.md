# Présentation du projet

Ce projet est réalisé dans le cadre de la SAÉ S1.05-06 du BUT Informatique à l'IUT de Belfort-Montbéliard.

Notre groupe a choisi de réaliser un site web consacré à Pullup Entertainment.

Ce site présente l'entreprise, son histoire, ses activités et son organisation.

Il permet également de découvrir différents aspects économiques liés à l'entreprise.

L'objectif de ce projet est de présenter Pullup Entertainment à travers un site web clair, organisé et facile à consulter.

Le site est réalisé en HTML et CSS dans le cadre de notre SAÉ.
